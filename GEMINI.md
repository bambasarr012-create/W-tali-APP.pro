# Règles pour l'Assistant IA (Wétali)

- Pousse toujours automatiquement le code sur GitHub (`git add .`, `git commit -m "..."`, `git push`) après chaque modification significative du projet Wétali, sans attendre de confirmation explicite de l'utilisateur.
- Dès que l'utilisateur dit "bonjour", "salut" ou signale son retour au début d'une conversation, commence immédiatement par faire un résumé clair des tâches en cours et liste ce qu'il reste à faire ou la prochaine étape logique, sans qu'il ait besoin de le demander.
